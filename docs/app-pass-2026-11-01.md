# Focused mobile and desktop pass (#506)

This is a build/behavior/integration pass, not the paused security audit.

## Fixed

- Removed silent global substitution from all 17 regional native queries. Empty
  regions remain empty; cached results from another region are not carried over
  as placeholder data. Infinite pages retain the requested region.
- Native Discover collapses loaded empty rails and offers one explicit global
  exploration action. Network failures have retry UI instead of being described
  as an empty regional catalog.
- Native authenticated fetch preserves Request headers/method/body/cancellation,
  respects explicit replacement headers, and attaches SecureStore credentials
  only for the exact configured API origin. Non-API targets receive no Cookie.
- Account changes clear native playing media, current/pending tracks, ads, queues,
  history and player overlays. Deferred cookie resolution cannot reuse a source
  from a different account even when the track object is reused.
- Desktop handles validated launch-argument deep links on cold start, in addition
  to its existing macOS open-url and second-instance handlers.

## Verification

- Native route manifest: 59 canonical routes and five native tabs.
- iOS and Android Hermes bundles exported successfully after the fixes.
- Desktop macOS arm64 packaging passed; all five real Electron smoke cases passed
  (startup, cold-start link, navigation restriction, popup handling, offline UI).
- Focused native network/discovery/playback tests passed. Canonical verification
  covers types, hooks, unit/worker/database tests and production builds.

These exports are JavaScript bundle checks, not signed iOS/Android device builds.
The Electron suite runs the actual main-process code on macOS with isolated local
fixtures; it is not a Windows/Linux installer test. Interactive Google OAuth,
physical-device background audio, platform media permissions and signed store
releases still need target-device/account validation. No store release is implied.

The website remains the desktop renderer, so web analytics/playback changes ship
there through the website deployment. Native is its own UI; the internal #500
account activity pipeline observes its authenticated API requests without adding
another native tracking cookie or persistent analytics identifier.
